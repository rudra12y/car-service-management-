Car Service Management System

A Premium Cloud-Connected Automotive Service & Detailing Booking Platform

  • Shivang Mistry: Frontend Lead (HTML5, CSS3, JS, Brotomotiv Theme, Modals)

Aim & Objectives of the Project

  • Automate Garage Operations: Eliminate traditional manual registration and long phone queues.
  • Modern UI/UX: Provide a high-end dark garage detailing theme with glowing orange accents inspired by Brotomotiv.
  • Instant Card Booking: Enable customers to book directly by clicking on visual service photo cards.
  • Lightweight Data Storage: Store live bookings in Excel (`.xlsx`) format without complex database overhead.

Software & Technologies Used

  • Frontend: HTML5, CSS3 (Glassmorphic UI), JavaScript (ES6 Fetch API)
  • Backend Framework: Python 3.14, Flask REST API, `flask-cors`
  • Database Engine: OpenPyXL (Automated Excel spreadsheet database)
  • Cloud Deployment: GitHub Pages (Frontend Hosting) & Render Cloud (Backend Server)
  • IDE & Tools: VS Code, Git, GitHub Desktop

Advantages of the System

  • Zero Maintenance Cost: Built completely using free-tier cloud infrastructure (GitHub Pages + Render).
  • Ultra-Fast Direct Booking: Direct card-click modal popup removes extra page reloads.
  • No DB Overhead: OpenPyXL eliminates heavy SQL/NoSQL setup requirements.
  • Fully Responsive: Seamlessly adapts to mobile, tablet, and desktop screens.
  • Real-time Admin Tracking: Live counter for total, pending, and completed service orders.

Disadvantages & Limitations

  • Excel Concurrency Limit: Excel handles small-to-medium traffic well, but huge simultaneous writes require a SQL database.
  • Render Cold Start: Render free instances go to sleep after inactivity and take 30–40 seconds to awaken on the first request.
  • Basic Security: Admin panel operates on direct route access without multi-factor or JWT authentication.

Future Scope & Upgrades

  • PostgreSQL / SQLite Integration: Migration from Excel to relational databases for scalable high traffic.
  • Online Payment Gateway: Integrating Razorpay / UPI for token amount confirmation.
  • Automated SMS/WhatsApp Alerts: Twilio API integration to send real-time service update messages.
  • Mechanic Dashboard: Dedicated portal for workshop mechanics to update task progress.
